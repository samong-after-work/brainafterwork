# samong-after-work

เว็บ React/Vite สำหรับแบรนด์ **samong หลังเลิกงาน**

## วิธีใช้กับ Vercel แบบง่าย

1. แตกไฟล์ ZIP นี้
2. อัปโหลดทุกไฟล์เข้า GitHub repository ชื่อ `samong-after-work`
3. เข้า Vercel
4. Add New → Project
5. เลือก repository นี้
6. กด Deploy

## คำสั่งสำหรับทดสอบในเครื่อง

```bash
npm install
npm run dev
```

## Build command

```bash
npm run build
```

Vercel จะตั้งค่าให้อัตโนมัติเป็น Vite
